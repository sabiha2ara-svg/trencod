Quick tutorials

Create and save

  1. Open Design → Visual game, Pixel & animation, or Vector art.
  2. Name your creation and press Save. Wait for a saved confirmation.
  3. Open My projects and reopen it to verify the saved version. Download editable backups regularly.

Team Studio

  1. Open Studio → Team Studios. Create a Studio and share its invite only with trusted teammates.
  2. Choose New shared code or New pixel animation. All members can edit shared creations.
  3. Save to team. If a teammate saved first, download your current work before reloading their version. Shared editing uses revision checks, not simultaneous live merging.
  4. Use Copy to My projects to create a personal code project. This is a separate copy.

Sell or buy a game

  1. Publish an original game, then open Creator Market and select it, set a TC price and credit terms.
  2. The listing contains a saved source snapshot. After editing your game, update its listing if you want to sell that newer version.
  3. A purchase transfers the project to one buyer as a private draft in My projects. The seller loses edit/publish access and the listing closes.
  4. Buyers can open their purchase from Creator Market. Report a purchase issue with the project/listing ID; never send account credentials.

TC are demo coins with no cash value. Older source licenses keep their previous terms. Browser source can be copied; exclusive platform ownership cannot erase downloaded copies or prove legal ownership.

Protect your progress

Wait for the saved confirmation, reopen from My projects, and keep an editable export. When a shared save conflicts, download your current version before reloading. Export personal projects requires login.
