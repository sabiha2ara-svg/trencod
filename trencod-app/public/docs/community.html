Create respectfully

  • Share work you created or have permission to use; preserve required credit.
  • No harassment, impersonation, malicious code or collection of other users’ passwords.
  • Keep private information out of public projects, chat and comments.
  • Report bugs with clear steps; do not attack creators for mistakes.

Studio controls

Invite trusted teammates only. Members can edit shared files. A Studio owner can remove members and reset invitations. Revision checks prevent silently replacing a teammate's newer saved file; this is not simultaneous collaborative editing.

Report a problem

Use private feedback. Include a project ID or relevant page and explain what happened. Support owners review manually. No 24/7 response or automated moderation guarantee is offered. A resolved status reflects the support owner's decision, not an independent review.
