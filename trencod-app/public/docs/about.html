A place to learn by creating

Trencod is a beta project by Saaiq Sajjad for playing, building and remixing browser games. Creators can work with code, visual scenes, pixel animation and vector artwork.

What you can use

  • Code and visual game editors, personal projects and team Studios.
  • Pixel and vector drawing, animation and supported music uploads.
  • Optional AI coaching, when the site owner has configured a provider.
  • A creator marketplace using demo Trencoins. TC have no cash value.

Current stage

This is a learning and development project, not a claim of enterprise readiness. Features may have bugs. Keep editable exports of important work. No independent security audit or guaranteed uptime is claimed.
