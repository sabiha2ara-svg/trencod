Trencod ko online laayein.

Code likhne ki zaroorat nahi. ZIP mein deployment settings ready hain.

1 · Pehle apne computer par kholo

  1. ZIP par right-click → Extract All.
  2. trencod-app kholo → START-TRENCOD.bat double-click.
  3. First run par internet aur Python 3.10+ chahiye. Server packages automatically install honge.
  4. Sign in → Create account. Username mein spaces nahi; password 8+ characters.

Website ko public/index.html double-click karke mat chalao. Sign-in ke liye running server chahiye.

2 · GitHub par source upload

  1. GitHub par naya repository banao: trencod.
  2. Add file → Upload files choose karo.
  3. ZIP ke trencod-app folder ke andar wali source files upload karo. Repository ke first page par server.py aur render.yaml dikhne chahiye.
  4. Commit changes dabao.

data aur .venv folders upload nahi karne. Unmein local accounts ya installed packages ho sakte hain.

3 · Render Blueprint se deploy

  1. Render dashboard kholo → New → Blueprint.
  2. GitHub connect karke apna trencod repository select karo.
  3. Render included render.yaml padhega. Ismein Python service aur data save rakhne wala disk configured hai.
  4. Charges papa ke saath review karo. Blueprint paid Starter service aur 1 GB disk use karta hai. Confirm karne par hosting charge lag sakta hai.
  5. Deploy complete hone ke baad Render ka https://…onrender.com link kholo.

Free static hosting par yeh full app nahi chalega. Accounts, games aur coins bachaane ke liye persistent database storage chahiye. Render ki normal files restart/redeploy par mit sakti hain.

4 · Do accounts se live test

  1. Normal browser mein account A se game publish karo.
  2. Incognito mein account B banao. Explore mein A ka game khelo.
  3. Remix dabao. B ki copy ko save aur publish karo.
  4. Studio room banao, doosre account ko invite karo aur shared art/code save karo. Creator Market mein game license kharid kar test karo.

Small test group se start karo. Real payments, seller payouts aur all-language execution abhi included nahi hain.

Purana account kaise bachayein?

Local update se pehle server band karo. Nayi source files purane trencod-app folder mein replace karo, lekin data folder rehne do. Database automatically upgrade hoga. Purane folder ki backup copy rakh lo.

Nayi hosted website ka database alag hoga. Local accounts automatically internet par transfer nahi hote.
